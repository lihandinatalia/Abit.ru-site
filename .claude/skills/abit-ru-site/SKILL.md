# Скилл: работа с сайтом Абит (Abit.ru-site)

Этот скилл помогает Claude Code быстро ориентироваться в проекте и выполнять типовые задачи
без лишних уточнений.

## Контекст проекта

- **Продукт:** корпоративный многостраничный сайт ООО «Абит» (abit-it.ru).
- **Тип:** статический HTML/CSS/JS без серверной части.
- **Цель сайта:** презентовать IT-услуги, генерировать заявки и обеспечивать доверие.
- **Язык контента:** русский.
- **Автор/владелец:** Наталья Лиханди.

## Структура репозитория

| Файл | Назначение |
|------|------------|
| `index.html` | Главная: услуги, преимущества, импортозамещение, о компании, CTA |
| `services.html` | Услуги с аккордеоном и ценами |
| `solutions.html` | Готовые решения (ИБ, резервирование, мониторинг, импортозамещение) |
| `projects.html` | Кейсы/проекты компании |
| `contacts.html` | Контакты и форма заявки |
| `privacy-policy.html` | Политика конфиденциальности |
| `styles.css` | Единая стилистика и адаптивность |
| `script.js` | Мобильное меню, reveal-анимации, активная навигация, форма mailto |
| `create-presentation.js` | Генератор PPTX на базе `pptxgenjs` |
| `abit-hero-v2.png` | Графика hero-блока |
| `README.md` | Описание проекта для GitHub |
| `.gitignore` | Исключение `node_modules`, логов, системных файлов |

## Технологии и ограничения

- **HTML5, CSS3, Vanilla JS (ES6+)** — без фреймворков.
- **Шрифт:** Google Fonts Inter.
- **CSS:** Custom Properties, Grid, Flexbox, адаптивные breakpoints: 1024px, 768px, 480px.
- **JS:** IntersectionObserver, плавная прокрутка, анимация аккордеона.
- **Зависимости:** только `pptxgenjs` для генерации презентаций.
- **Сайт статический:** для запуска достаточно браузера, сервер не нужен.

## Как запустать и проверять

### Запуск сайта
1. Открыть `index.html` (или любую другую страницу) в браузере.
2. Для проверки на мобильных разрешениях — DevTools Responsive Mode.

### Генерация презентации
```bash
cd "C:/Users/User/Presents y landings/Abit.ru-site"
npm install
node create-presentation.js
```

### Проверка ошибок
Обязательно проверять после любых изменений:
1. **Консоль браузера** — ошибки JS.
2. **Адаптивность** — ширины 1024, 768, 480 px.
3. **Мобильное меню** — бургер открывается/закрывается, ссылки закрывают меню.
4. **Аккордеон услуг** — плавное раскрытие/скрытие.
5. **Форма заявки** — при submit формируется `mailto:` с темой и телом письма.
6. **Reveal-анимации** — блоки появляются при скролле.
7. **PPTX-генератор** — запускается без ошибок, файл создаётся.

### HTML/CSS валидаторы
- https://validator.w3.org/ для HTML.
- https://jigsaw.w3.org/css-validator/ для CSS.

## Правила внесения изменений

1. **Сохранять единый дизайн:**
   - Использовать существующие CSS-переменные из `:root` (`--bg`, `--text`, `--cyan`, `--violet`, `--pink`, `--accent-gradient` и др.).
   - Не добавлять новые цвета без явной необходимости.
   - Для новых блоков использовать классы `.section`, `.container`, `.card`, `.reveal`.

2. **Адаптивность:**
   - Каждый новый блок должен корректно смотреться на 1024px, 768px, 480px.
   - Добавлять медиазапросы в `styles.css` в соответствующий breakpoint.

3. **Анимации:**
   - Добавлять класс `.reveal` к элементам, которые должны появляться при скролле.
   - Fallback для скриншотов/print уже реализован в `script.js`.

4. **Контент:**
   - Все новые тексты на русском языке.
   - Телефон и email должны совпадать с `contacts.html`.

5. **Формы:**
   - При добавлении новых форм сохранять логику `mailto:` из `script.js`.
   - Использовать семантичные `<label>`, `<input>`, `<textarea>`.

6. **Страницы:**
   - При добавлении новой HTML-страницы добавить ссылку в `<nav>` в `index.html`
     и во все остальные HTML-файлы, а также в footer.

## Подготовка к публикации

1. Проверить `git status` — убедиться, что ненужные файлы не добавлены.
2. Убедиться, что `node_modules` в `.gitignore`.
3. Если нужно — выполнить `npm install` и проверить `node create-presentation.js`.
4. Сделать коммит:
   ```bash
   git add .
   git commit -m "Описание изменений"
   git push origin master
   ```
5. Если нужно переименовать ветку `master` в `main`:
   ```bash
   git branch -M main
   git push -u origin main
   ```
